# My Voice AAC Support Website

Files:
- index.html — website home page
- support.html — use this as the App Store Connect Support URL
- privacy.html — use this as the App Store Connect Privacy Policy URL
- style.css — website styling

## Publish with GitHub Pages
1. Create a PUBLIC GitHub repository named `my-voice-aac-support`.
2. Upload all four files to the repository root.
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Select `main` and `/ (root)`, then Save.
6. After GitHub publishes the site, the URLs will normally be:
   https://YOUR-USERNAME.github.io/my-voice-aac-support/
   https://YOUR-USERNAME.github.io/my-voice-aac-support/support.html
   https://YOUR-USERNAME.github.io/my-voice-aac-support/privacy.html

Use support.html for App Store Connect's Support URL.
Use privacy.html for App Store Connect's Privacy Policy URL.

Before App Store submission, verify the published pages and make sure the privacy policy matches the exact shipping build.
