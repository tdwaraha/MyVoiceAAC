Common Questions

How do I make the app speak?

Tap vocabulary buttons to build a message in the sentence bar, then use the Speak button. If Auto Speak is enabled, selected vocabulary can also be spoken as you communicate.

Can I personalize vocabulary?

My Voice AAC includes tools for customizing vocabulary and can use personal photos and recorded voice where those features are enabled.

Why does the app ask for camera, photo or microphone access?

These permissions support optional personalization features such as choosing or taking a picture and recording a voice for a vocabulary button. You can manage permissions in iOS Settings.

Can I use different profiles?

The app supports communication profiles so vocabulary can be personalized for different users or setups. Profile import and export can also be used for backup or transfer.

Is an internet connection required?

Core AAC communication is designed to work on the device. Some iOS or optional external services may depend on system availability.

Accessibility

My Voice AAC is designed around clear visual communication and large interactive controls. If you experience an accessibility problem, please contact support so it can be investigated.
